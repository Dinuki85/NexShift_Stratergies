# ⚙️ NEX Shift Strategies Pvt Ltd – Frontend

> ✨ Connecting Supply Chains Today, Driving Innovation Tomorrow

This is the **frontend** of the NEX Shift Strategies website – a sleek, professional, and responsive web interface built with **React.js**, **Next.js**, and **Tailwind CSS**.

---

## 🔥 Features

- 💼 Clean landing page with animated content and slide transitions  
- 📸 Dynamic background image slideshow  
- 📧 Contact form (integrated with backend to send emails)  
- 📱 Fully responsive across all devices  
- 🎨 Styled with modern utility-first Tailwind CSS  
- 🔐 Contact modal with form validation  

---

## 🚀 Tech Stack

| Technology     | Description                                  |
|----------------|----------------------------------------------|
| React.js       | Component-based frontend framework           |
| Next.js        | React framework with server-side rendering   |
| TypeScript      | Strict type safety and maintainability |
| Tailwind CSS   | Utility-first CSS for beautiful design       |
| Axios          | For API calls to backend                     |
| Vercel Ready   | Ideal for hosting on Vercel or Netlify       |
